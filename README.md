# NeuraLite

A neural network written **from scratch in pure NumPy** — no PyTorch, no
TensorFlow, no autograd. Every forward pass, backward pass, loss gradient,
and optimizer update is hand-derived. Correctness is proven, not assumed:
the test suite numerically gradient-checks every layer and loss against
finite differences (tolerance 1e-5).

## Architecture

```
Input (2-D)
   │
┌──▼───────────┐
│ Linear(2→64) │  y = x·Wᵀ + b      (He init)
│ ReLU         │  max(0, x)
│ Linear(64→64)│
│ ReLU         │
│ Linear(64→3) │  logits (no softmax here)
└──┬───────────┘
   ▼
┌──────────────┐
│ CrossEntropy │  log-softmax + NLL, numerically stable
│    Loss      │  dL/dlogits = (softmax − onehot) / N
└──┬───────────┘
   ▼
┌──────────────┐
│ Adam / SGD   │  from-scratch updates (Adam w/ bias correction,
│  Optimizer   │  SGD w/ momentum); minibatch loop in Sequential.fit()
└──────────────┘
```

Backpropagation flows right-to-left through the same graph: each layer's
`backward(dout)` implements the exact Jacobian-vector product for its
forward op (see `neuralite/layers.py` — the derivations are in the comments).

## Quickstart

```bash
make setup   # pip install numpy, matplotlib, pytest
make test    # 22 tests, incl. gradient checks for all layers/losses
make demo    # train a 2×64 MLP on 3-arm spirals, save plots to examples/
```

## Results

Measured with `make demo` on 2026-10-03 (CPU-only, ~8 s wall-clock).
2,100-point 3-arm spiral dataset, 2→64→64→3 MLP, Adam (lr=1e-2),
400 epochs, batch size 64. No numbers below are invented.

| metric | value |
|---|---|
| train accuracy | 0.9107 |
| val accuracy | 0.9143 |
| final train loss | 0.1973 |

A 1-nearest-neighbor probe on the same data scores 0.895, so the network is
performing at roughly the Bayes limit of this noisy dataset — the remaining
errors are overlapping points near the spiral arms, not underfitting.

`examples/spiral_results.png` (generated by the demo) shows the learned
decision boundary and the train/val loss curves.

## The math it implements

- **Linear**: `dW = doutᵀ·x`, `db = Σdout`, `dx = dout·W`
- **ReLU/Sigmoid/Tanh**: elementwise `dout · f′(x)` (sigmoid uses a
  branch-on-sign formulation so `exp()` never overflows)
- **Softmax**: `dxᵢ = sᵢ·(doutᵢ − Σⱼ doutⱼ·sⱼ)` per row
- **Cross-entropy (logits)**: `dlogits = (softmax(logits) − onehot(y)) / N`
- **MSE**: `dpred = 2·(pred − target) / (N·D)`
- **Adam**: moment estimates with bias correction (Kingma & Ba, 2014)
- **SGD**: `v ← μ·v − lr·g`, `p ← p + v`

Two subtle points the implementation gets right:
gradients **accumulate in place** (`+=`) because optimizers hold references
to the gradient arrays — rebinding them would silently freeze training; and
`zero_grad()` fills in place for the same reason.

## Limitations (read before judging it)

- **Educational, not a framework competitor.** No GPU, no vectorized batch
  tricks beyond NumPy, no dynamic graphs — it exists to show the math working.
- **Small scale.** The demo is 2-D spirals; nothing here is tested on real
  high-dimensional data.
- **Spiral difficulty is tunable.** The generator's `winding`/`noise`
  parameters control arm overlap; the defaults (4.0 rad, 0.1) keep the
  problem learnable (verified: 1-NN ≈ 0.90).
- **Heuristic scope.** No learning-rate schedules, no regularization, no
  convolutions — just dense layers, the activations above, and two
  optimizers.

## Project layout

```
NeuraLite/
├── neuralite/
│   ├── layers.py     # Linear, ReLU, Sigmoid, Tanh, Softmax + backward passes
│   ├── losses.py     # CrossEntropy (logits), MSE + gradients
│   ├── optim.py      # SGD w/ momentum, Adam — from scratch
│   ├── model.py      # Sequential, minibatch fit() with train/val tracking
│   ├── data.py       # spiral generator + train/val split (NumPy only)
│   └── gradcheck.py  # numerical gradient verification utility
├── scripts/demo.py   # train on spirals, save decision-boundary plot
├── tests/            # grad checks, optimizer math, overfitting, loss curves
└── examples/         # spiral_results.png (generated by the demo)
```
